Welcome to the **StudioBridge** documentation.

StudioBridge provides verified, reversible, and local control of FL Studio for coding agents and automation tools.

## Key Features

- **One bridge, every control surface**: Live session control, offline `.flp` project parsing and manipulation, headless audio rendering, and UI actuation.
- **Truthful capability reporting**: Hardware and FL build capability reporting without guesswork or silent failures.
- **Reversible by default**: Read-only session mode, atomic mutations, and mutation journaling.
- **Local and open**: MIT licensed, local execution with zero telemetry.
